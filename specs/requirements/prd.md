# Team notes

## Problem Statement

Team members have no single shared place to keep short notes everyone can read, so notes scatter across personal tools and the important ones get lost.

## Solution

Team notes is a small web app with an API where signed-in team members list, read and create the team's notes, and pin the important ones so they show first.

## Actors

- Member: a signed-in team member. The only role; can list, read, create and pin notes.
